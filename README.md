# 한 줄 카페 — JavaScript 학습 타이쿤

카페 운영 상황을 통해 JavaScript 개념을 배우는 브라우저 학습 시제품입니다.

## 학습 챕터

1. 오픈 준비: 문자열, 숫자, 불리언
2. 계산대 점검: typeof, Number()를 통한 형변환
3. 예약 정보 관리: undefined와 null

## 실행

index.html을 브라우저로 열면 됩니다. 별도 설치, 서버, 외부 라이브러리가 필요 없습니다. 진행은 메모리에만 보관되어 새로고침하면 초기화됩니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save

HTML, CSS, JavaScript 원본은 각각 index.html, style.css, script.js입니다.
