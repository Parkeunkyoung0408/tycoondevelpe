DAY 02 · typeof와 형변환

키오스크에서 새 주문이 왔어요

가격과 수량이 글자로 도착했어요. 두 값을 더하면 어떤 결과가 될까요? 먼저 자료형을 확인해봐요.

예약 주문 · 커피 2잔



typeof는 값의 종류를 확인하는 연산자예요. 결과도 "string" 같은 문자열로 돌아와요.
가격을 글자로 두 번 더하면
글자로 된 금액은 +로 이어 붙여져요. 실제 주문을 계산하려면 숫자로 바꿔주세요.


형변환은 값의 자료형을 바꾸는 일이에요. Number()는 이 숫자 모양의 문자열을 숫자로 바꿔요.
typeof로 확인 → Number()로 변환 → 숫자로 계산해서 실제 매출에 반영했어요.


DAY 03 · undefined와 null
픽업 시간이 아직 안 왔어요
새 예약의 픽업 시간은 아직 전달받지 못했어요. 이번에는 이 정보를 변수로 관리해봐요.
🛍️ 민지님의 예약
픽업 시간: 아직 정해지지 않음
쿠폰: 아직 확인 전
let pickupTime;
let coupon;


pickupTime; // undefined
typeof pickupTime; // "undefined"
변수는 만들었지만 값을 넣지 않아서 undefined예요. 이 예약에서는 ‘시간을 아직 받지 못했다’는 상태로 사용해요. 변수를 선언하지 않은 것과는 달라요.


손님에게 확인했어요. “쿠폰은 사용하지 않을게요.”
null은 값이 없다는 것을 의도적으로 표시할 때 써요. 이 예약에서는 ‘확인 결과 쿠폰 없음’으로 정했어요.
typeof null은 왜 "object"예요?
JavaScript의 오래된 특성이에요. null이 실제 객체라는 뜻은 아니에요. null 여부는 coupon === null로 확인해요. null과 undefined는 서로 다른 원시 값이에요.
undefined: 변수를 만들고 값을 아직 넣지 않음
null: 값이 없다고 직접 넣어 표시함
‘미정’과 ‘없음’이라는 의미는 이 게임에서 정한 사용 규칙이에요.
